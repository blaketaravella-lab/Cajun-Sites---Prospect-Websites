# Cajun Sites - Prospect Websites

Central repository for CajunSites prospect/demo websites.

## Prospect rule

A business is only eligible for a prospect mockup when its Google Business Profile does **not** show a Website button. If any website is listed, including a third-party destination, the business is removed from the prospect pipeline.
